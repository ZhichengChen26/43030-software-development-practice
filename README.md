# 43030 Software Development Practice

This repository was created for Goal 3 of my 43030 Professional Learning Plan.

## Purpose

The purpose of this repository is to practise Git, GitHub and basic software development workflows.

## What I Practised

- Creating and managing a GitHub repository
- Making commits and tracking changes
- Working with the main branch
- Creating a simple HTML file
- Writing a YAML workflow
- Using GitHub Actions
- Running an automated project check

## GitHub Actions Workflow

The workflow automatically runs when changes are pushed to the main branch. It checks that the README.md and index.html files exist in the repository.

This activity helped me understand how automated workflows can support software development by checking project files after changes are committed.
